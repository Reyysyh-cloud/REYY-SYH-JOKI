1. Buka folder ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK debug akan berada di app/build/outputs/apk/debug/app-debug.apk.
5. Install APK tersebut ke HP Android.

Catatan: website memakai Tailwind CDN, jadi koneksi internet diperlukan untuk tampilan Tailwind saat aplikasi pertama kali dijalankan.
